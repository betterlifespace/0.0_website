# Model 1 — BetterLifeSpace website (static)

This folder contains "Model 1" — a complete static single-page marketing site you can preview and iterate on.

Files:
- `index.html` — main single-page site
- `assets/css/style.css` — styles
- `assets/js/main.js` — small JS for mobile nav and UX
- `.nojekyll` — allows GitHub Pages to serve files and folders starting with `_`

How to preview:
- Open `models/Model 1/index.html` in a browser.
- For a better dev flow, use VS Code Live Server or `npx http-server` from the folder root.

Deployment options:
- Publish branch `models/model-1` to GitHub Pages, or merge into `main` and enable Pages from `main`.
- Add a custom domain by adding `CNAME` to the root and configuring DNS.
